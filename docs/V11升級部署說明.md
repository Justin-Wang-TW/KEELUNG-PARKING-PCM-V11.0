# V11.0 升級部署說明

V11 同時改了前端與後端的登入方式，**兩邊必須一起上線**。只更新其中一邊，所有人都會無法登入。建議照下面順序操作，整個過程約 30–40 分鐘，請選在下班時間進行。

---

## 一、事前準備（建議先在測試環境驗證）

1. 在 Google 雲端硬碟對正式試算表按「建立副本」，命名為「履約管理_測試」。副本會連同綁定的 Apps Script 一起複製。
2. 開啟副本 →「擴充功能」→「Apps Script」，依照「二、更新後端」的步驟 1–5 操作。
3. 在副本的 Apps Script 按「部署」→「新增部署作業」→ 類型「網頁應用程式」，執行身分選「我」，存取權選「所有人」，取得**測試用網址**。
4. 在電腦上把 `constants.ts` 的 `SCRIPT_URL` 暫時改成測試用網址，執行 `npm install`、`npm run dev`，用「四、上線後測試清單」逐項測試。
5. 測完把 `SCRIPT_URL` 改回正式網址（**不要**把測試網址推上 GitHub）。

> 測試環境的提醒信會真的寄出。測試前可在副本的「專案設定 → 指令碼屬性」新增 `REMINDERS_ENABLED` = `false`。

---

## 二、更新後端（正式試算表的 Apps Script）

1. **備份目前程式**：把 Apps Script 裡的 `Code.gs` 全選複製，另存一份文字檔（你已有 `Code.gs.txt`）。
2. **更新 `Code.gs`**：全部內容換成 `gas/Code.js`。
3. **新增 `Setup.gs`**：左側「檔案 ＋」→「指令碼」，命名 `Setup`，貼上 `gas/Setup.js`。
4. **更新資訊清單**：「專案設定」勾選「在編輯器中顯示 appsscript.json」，回到編輯器開啟 `appsscript.json`，換成 `gas/appsscript.json`（新增了排程觸發器權限 `script.scriptapp`）。
5. **預覽資料整理**：上方函式選單選 `previewMigrationV11` → 執行。第一次會要求授權，請用系統擁有者帳號（justin@3dmove.com.tw）同意。執行完到「執行記錄」確認要修改的內容，例如：
   - `成功立體停車場` → `CHENG`
   - `2026-08-24T16:00:00.000Z` → `2026-08-25`
6. **正式升級**：函式選 `setupV11` → 執行。它會依序：
   1. 自動備份整份試算表（檔名含「V11升級前備份」）
   2. 產生密碼 Pepper（指令碼屬性 `PASSWORD_PEPPER`，**請勿刪除**）
   3. 整理 `1_任務執行表`：補齊 17 欄標題、場站代碼、日期格式
   4. 修正 `2_每月場館檢核紀錄` 標題列
   5. 建立 `10_任務留言` 分頁
   6. 舊的 `9_系統說明與參數` 改名為「_舊版」，重建新版說明
   7. 安裝 3 個排程（每日 00:10、每日 08:30、每週一 08:30）
   8. 立即標記逾期工項
7. **發布新版本**：「部署」→「管理部署作業」→ 選目前正式的部署 → 鉛筆圖示 →「版本」選「新版本」→「部署」。
   **這樣網址不變**，前端的 `SCRIPT_URL` 不需修改。

---

## 三、更新前端

1. 把整個專案資料夾的變更推送到 GitHub（Vercel 會自動部署）。
2. 部署完成後，打開正式網址，按 Ctrl+F5 強制重新整理。
3. **所有使用者都需要重新登入一次**，密碼不變。

| 13 | 確認舊訊息無誤後，執行 `redactPlaintextPasswords` | `Messages` 分頁中的「預設密碼：xxxx」變成「預設密碼：（已移除）」，網址保留 |

## 五、如果需要回復舊版

1. Apps Script「管理部署作業」→ 編輯正式部署 → 版本選回升級前的版本 → 部署。
2. GitHub 回復前端到升級前的 commit。
3. **注意密碼**：V11 會在使用者登入時把密碼改存成新格式，舊版後端看不懂。回復舊版時，請把「V11升級前備份」試算表的 `3_使用者權限表` F 欄（密碼）複製回正式試算表。在 V11 期間改過密碼或新核准的帳號，需要由管理員重設密碼。
4. 「管理觸發條件」頁面刪除 `dailyMaintenance`、`dailyReminders`、`weeklySummary` 三個排程。

## 六、常用設定（Apps Script「專案設定」→「指令碼屬性」）

| 屬性 | 說明 |
|---|---|
| `SYSTEM_URL` | 信件中的登入連結，預設 `https://keelung-parking.vercel.app/` |
| `REMINDERS_ENABLED` | 設 `false` 暫停所有自動寄信（提醒信、週報、退回通知、缺失通知） |
| `UPLOAD_FOLDER_ID` | 附件上傳資料夾 ID；測試環境可設為另一個資料夾，避免測試檔案混入正式附件 |
| `PASSWORD_PEPPER` | 系統自動產生，**刪除或修改會讓所有人無法登入** |

Email 以部署者帳號寄出，Google Workspace 帳號每日上限約 1,500 封。提醒信每人每天最多一封彙整信。
